# Product Quality Inbox

## Active assignment
- Review the current task for product completeness, acceptance fit, and release readiness.

## Scope
- Evaluate whether the implementation matches the user intent and product goals.
- Check cross-page consistency, edge cases, and user-visible gaps.
- Focus on product quality rather than runtime test execution.

## Acceptance criteria
- Summarize whether the scope is complete and coherent.
- Call out missing requirements, polish issues, and product risks.
- Distinguish blockers from non-blocking follow-ups.

## Handoff
- Record results in `PROGRESS.md`.
- Log transition in `HANDOFFS.md`.
- Return findings to `techlead`.
