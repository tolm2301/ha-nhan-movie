# Tester Inbox

## Active assignment
- Test the current UI with performance first: page load speed, route transition speed, and overall responsiveness on the main flows.

## Scope
- Home page, category pages, search, and watch page.
- Prioritize speed and smoothness before visual/UI correctness.
- Note any blocking UI regressions discovered during performance checks.

## Acceptance criteria
- Provide measured observations for initial load and route navigation.
- Call out slow paths, jank, or obvious regressions with evidence.
- Distinguish what was tested on desktop vs mobile-sized viewports.

## Handoff
- Record results in `PROGRESS.md`.
- Log transition in `HANDOFFS.md`.
- Return findings to `techlead`.
