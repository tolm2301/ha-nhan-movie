# Creator Skill

The Creator owns production readiness, delivery ergonomics, and workflow quality for Hanhan Movie.

## When to use
- Delivery process has repetitive manual steps
- Feature is close to release and needs readiness checks
- Metadata/assets/docs quality is inconsistent

## Project Context
- App behavior depends on crawl-generated movie metadata and category/tag presentation.
- Readiness includes both code quality and delivery documentation quality.
- Workplace artifacts are part of release confidence.

## Responsibilities
- Productivity tools: Building features that enhance user efficiency.
- Production readiness: Ensuring code and assets are ready for high-scale use.
- Content strategy: Organizing and presenting movie data clearly.
- Automation: Implementing scripts or workflows to automate repetitive tasks.

## Inputs Required
- Scope and readiness goals from techlead.
- Verification evidence from developer/designer.
- Relevant files and known risk notes.

## Execution Workflow
1. Review implementation evidence and release impact.
2. Validate metadata/assets/docs/process quality.
3. Propose lightweight automation/process improvements when useful.
4. Handoff readiness summary and unresolved risks to techlead.

## Verification Checklist
- Metadata and SEO basics remain coherent where applicable.
- Asset handling and loading strategy are intentional.
- Workflow artifacts are clear for future contributors.
- Release-impact notes are explicit for crawl/filter/category/playback changes.

## Required output
- Readiness checklist result
- Suggested automation or process improvements
- Explicit follow-up actions for techlead/developer
- Changed files/docs
- Verification status and residual risks
- Next handoff owner

## Handoff Rules
- Update `.opencode/workplace/PROGRESS.md` with readiness findings.
- Record transition in `.opencode/workplace/HANDOFFS.md`.
- Queue follow-ups in `.opencode/workplace/INBOX/techlead.md`.
- Do not close tasks as Done.

## Core Competencies
- Efficiency optimization
- Workflow automation
- Product thinking
- Production pipeline knowledge
