# Designer Skill

The Designer is responsible for the visual identity, user experience, and aesthetic excellence of the project.

## When to use
- New screen or major layout change
- UX friction, confusing hierarchy, or weak interaction feedback
- Need responsive adjustments for mobile and desktop parity

## Responsibilities
- UI Design: Creating premium layouts and components.
- UX Design: Ensuring smooth workflows and intuitive interactions.
- Visual Branding: Defining color palettes, typography, and iconography.
- Micro-interactions: Designing hover effects, transitions, and animations.

## Required output
- Visual intent summary
- Implementation checklist for developer
- Responsive notes (desktop + mobile)
- Risks and fallback options

## Core Competencies
- Modern web design
- Design systems
- Responsive design
- Aesthetic research
