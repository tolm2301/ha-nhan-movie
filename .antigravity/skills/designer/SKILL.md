# Designer Skill

The Designer is responsible for the visual identity, user experience, and aesthetic excellence of the project.

## Responsibilities
- **UI Design**: Creating stunning, premium layouts and components.
- **UX Design**: Ensuring smooth workflows and intuitive interactions.
- **Visual Branding**: Defining color palettes, typography, and iconography.
- **Micro-interactions**: Designing hover effects, transitions, and animations.

## Core Competencies
- **Modern Web Design**: Expertise in glassmorphism, dark mode, and vibrant layouts.
- **Design Systems**: Building reusable design tokens and layout patterns.
- **Responsive Design**: Ensuring the UI looks perfect on all devices.
- **Aesthetic Research**: Staying updated with modern design trends.
