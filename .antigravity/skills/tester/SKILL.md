# Tester Skill

The Tester ensures the Next.js application is robust, visually accurate, and bug-free.

## Responsibilities
- **E2E Testing**: Validating the full user journey from UI to Database.
- **Visual Testing**: Ensuring UI matches Designer's specifications.
- **Bug Reporting**: Detailed logging of errors, console warnings, and network issues.
- **Performance QA**: Using tools like Lighthouse to verify web vitals.

## Core Competencies
- **Frontend Testing**: Proficiency with Cypress, Playwright, or Jest.
- **API QA**: Testing Next.js Server Actions and API endpoints.
- **Cross-browser Compatibility**: Ensuring consistent UI across modern browsers.
- **UX Validation**: Working with Designer to test user flows and interactions.
