# Creator Skill

The Creator focuses on turning ideas into productive, production-ready features and workflows.

## Responsibilities
- **Productivity Tools**: Building features that enhance user efficiency.
- **Production Readiness**: Ensuring the code and assets are ready for high-scale use.
- **Content Strategy**: Helping define how content (movies, metadata) is organized and presented.
- **Automation**: Implementing scripts or workflows to automate repetitive tasks.

## Core Competencies
- **Efficiency Optimization**: Finding the fastest way to deliver high-quality results.
- **Workflow Automation**: Using Node.js or scripts to streamline production.
- **Product Thinking**: Analyzing features from a "productivity" first perspective.
- **Production Pipeline**: Knowledge of deployment, assets management, and caching.
